# Formulário de matrícula | Estrelas do Amanhã

Página de matrícula para a escola de educação infantil **Estrelas do Amanhã**. O projeto apresenta um formulário organizado por etapas de informação e uma ilustração que acompanha a identidade visual da escola.

## Sobre o projeto

A página permite preencher, em uma única tela, dados da criança, endereço, informações do responsável e preferências de matrícula. O layout foi pensado para telas grandes e pequenas, reorganizando o conteúdo para dispositivos móveis.

## Tecnologias

- **HTML5** — estrutura semântica da página e campos do formulário.
- **CSS3** — estilos, layout em colunas, componentes e adaptação para telas menores.

## Funcionalidades da interface

- Campos para informações pessoais e médicas da criança.
- Seleção de arquivo para a certidão de nascimento.
- Campos de endereço e informações do responsável.
- Seleção de turno e atividade esportiva.
- Opção para concordar com os termos e botões de ação.
- Layout responsivo para desktop e dispositivos móveis.

## Como visualizar

Veja a versão publicada: [Formulário de matrícula | Estrelas do Amanhã](https://edivilhian-h.github.io/Formulario-de-matricula/).


## Observação

Este projeto é uma interface de front-end. O formulário ainda não está conectado a um servidor ou serviço de matrícula, e ações como salvar respostas precisam de implementação para funcionar de ponta a ponta.
